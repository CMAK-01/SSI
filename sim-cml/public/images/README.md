# Logo de l'application

Le logo actuel est `logo.jpg` (CML — Compagnie Minière du Littoral).

Pour le remplacer, déposez ici votre image sous l'un des noms suivants :

- `logo.jpg` / `logo.jpeg` (**recommandé** — compatible PDF sans configuration)
- `logo.png` (nécessite l'extension GD active sous Apache pour les PDF ;
  pensez à supprimer l'ancien `logo.jpg` pour qu'il soit pris en compte)

Le logo sera automatiquement détecté et affiché :

- dans l'en-tête de l'application (à côté de « SIM-CML »)
- en haut de tous les exports **PDF**
- en haut de tous les exports **Excel** (rapport mensuel, parc informatique, rapport de diagnostic)

Format recommandé : JPEG ou PNG, fond blanc, ~1200×500px.
